# Manuel Utilisateur - AeroportSPA

Bienvenue dans le manuel d'utilisation de **AeroportSPA**. Cette application web (Single Page Application) vous permet de gérer facilement un réseau aéroportuaire, incluant les vols, les aéroports, les compagnies aériennes, les villes et les pays.

---

## 1. Vue d'ensemble et Navigation

L'application est conçue pour être intuitive. En haut de l'écran, vous trouverez la barre de navigation principale qui vous permet d'accéder aux différentes sections de l'application.

- **Menu de Navigation :** Vous permet de basculer de manière fluide entre les vues "Home", "Vols", "Aéroports", "Compagnies", "Villes" et "Pays".
- **Thème Clair / Sombre :** En haut à droite, un bouton (☀️/🌙) vous permet de basculer entre le mode clair et le mode sombre selon vos préférences.
